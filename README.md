# .github

Perfil público da organização **LP Solutions Group**.

O GitHub renderiza o `profile/README.md` deste repositório na página
`github.com/LP-Solutions-Group`, e só o faz se o repositório for **público**.

## Antes de commitar aqui, leia

Este é o único repositório da organização feito para ser público. Isso quer
dizer que **arquivo, histórico e mensagem de commit são texto público** — e
histórico de repositório público não se apaga: um `--force` deixa o commit
antigo órfão e ainda alcançável por SHA.

Escreva a mensagem como quem escreve nota para fora, não como nota de
engenharia. Nada sobre como as extensões obtêm dado, sobre atrito com
plataforma de terceiro, sobre limite do nosso processo, endereço interno,
preço ou número de clientes.

Este repositório foi recriado em 13/10/2026 justamente por isso: a primeira
versão de uma mensagem de commit descrevia mecanismo de coleta, e recriar foi
a única forma de o objeto antigo deixar de existir.
